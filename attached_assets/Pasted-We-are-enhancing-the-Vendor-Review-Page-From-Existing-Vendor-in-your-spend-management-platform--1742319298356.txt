We are enhancing the "Vendor Review Page (From Existing Vendor)" in your spend management platform, Stride, a B2B SaaS app built with React (Vite) and Flask on Replit. The goal is to add an editing workflow for existing vendors. When the user clicks the "Edit" button on the "Vendor Review" page (accessed via sourceRoute="newBill"), they will be directed to a new "Vendor Information" page. This page will reuse the design and fields of the "New Vendor" page, prefilled with the existing vendor’s data. The page will include "Save Changes" and "Discard Changes" buttons to either update the vendor information or revert to the original data, respectively, before navigating back to the "Vendor Review" page.

Here’s the step-by-step implementation guide for Replit:
Create the "Vendor Information" Component
Since the "Vendor Information" page should mirror the "New Vendor" page, we’ll assume you have a NewVendor.jsx component with the necessary fields, styles, and layout. If not, we’ll create it and reuse it for both purposes. For now, let’s create a VendorInformation.jsx component based on a typical vendor form layout.

In frontend/src/components/VendorInformation.jsx:
