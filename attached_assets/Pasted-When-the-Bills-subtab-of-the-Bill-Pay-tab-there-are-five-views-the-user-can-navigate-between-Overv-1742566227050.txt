When the Bills subtab of the Bill Pay tab there are five views the user can navigate between. 
Overview, Draft, For Approval, For Payment and Histroy. The data within the tables is not user genereated, but users might have some control to edit it. 
The Overview tab has these columns:
Checkbox
Vendor (Text)
Amount (Currency - INR - Rupee Icon)
Invoice Date (Date)
Invoice # (Number)
Invoice (File) - the actual invoice file the user the click on to view the invoice pdf copy
Department (Text)
Due Date (Date)
Action (Button to either Review, Reject or Approve. The bill can only be in Review when it is in Draft foramt. And it can only be Rejected or Approved by Specfic indiviauls. ) 
Status (Text)
Payment Status (Dropdown - Pending, initiated, scheduled)
Payment Date (Date)
Approval Status (ENUM or VARCHAR (with constraints))
Category (Text)
PO# (number)
