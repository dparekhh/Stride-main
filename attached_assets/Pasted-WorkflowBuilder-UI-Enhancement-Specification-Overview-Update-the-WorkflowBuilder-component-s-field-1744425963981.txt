WorkflowBuilder UI Enhancement Specification
Overview
Update the WorkflowBuilder component's field selection and condition boxes to improve usability and visual consistency.

Target Changes
1. Field Selection Box Width
Currently analyzing WorkflowBuilder.jsx, the field selection box appears in the handleRequirementsClick function with a standard width. We need to:

Increase width from current fixed width to match the Set conditions box width
Maintain consistent padding and margins
Ensure responsive behavior on different screen sizes
2. Field Selection Dropdown Overlay
The dropdown positioning issue is visible in the component where the fieldSelectionDropdownRef is used. To fix:

Update dropdown positioning to use fixed positioning
Ensure dropdown overlays other content
Maintain proper z-index hierarchy
Handle scroll behavior appropriately
3. Set Conditions Box Styling
The orange border/highlight appears in hover states within the Set conditions interface. Changes needed:

Remove orange highlight/border from condition option boxes
Maintain consistent hover state styling
Keep focus states accessible
